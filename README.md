# Voice Robot 项目启动说明

本项目包含一个基于 Python (FastAPI/WebSockets) 的后端服务，以及一个基于 Tauri (Vue + Rust) 构建的桌面端前端应用。

## 1. 启动后端 (Python)

后端负责大模型对话、语音处理、天气查询等核心业务逻辑。项目使用了 `uv` 进行环境和依赖管理。

### 推荐启动方式 (使用 uv)
请在项目根目录下，打开终端并运行以下命令：
```bash
uv run python backend/main.py
```

### 备用启动方式 (使用内置虚拟环境)
如果您没有全局安装 `uv`，但当前目录下存在 `.venv` 虚拟环境，可以直接使用内部的 python 解释器启动：
```bash
.\.venv\Scripts\python.exe backend/main.py
```

**提示：** 后端启动成功后，通常会监听端口（如 8000、8765 等），并在终端打印相关的启动日志。请确保后端正常运行且无报错，再前往启动前端。

---

## 2. 启动前端 (Tauri + Vue)

前端是一个独立的图形界面应用，依靠 Node.js 结合 Tauri (Rust) 打包与运行。

请在项目根目录下**重新开启一个新的终端窗口**，然后执行以下命令启动：
```bash
npm run tauri dev
```

**提示：** 
- 首次运行该命令时，Tauri 可能需要额外的时间去下载依赖并编译 Rust 相关的系统组件，请耐心等待。
- 编译完成后，会自动弹出一个独立的桌面应用程序窗口供您进行交互。
